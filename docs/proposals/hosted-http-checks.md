# Anonymous hosted HTTP release observation

Prepared 7 November 2026; corrected edition awaiting execution. The first remote packet observed a complete anonymous homepage 200, then failed because its path grammar omitted the eight observed `/_next/static/immutable/chunks/` script URLs. That [failed result](../results/2026/11-07/hosted-http-attempt-1.md) stays false; the correction admits only the two explicit static chunk prefixes. Local DNS and the independent public web fetch remain separate negative observations. This public Ubuntu packet uses builtin Node HTTPS; it does not recover credentials, create a Vercel share link, bypass protection or retry an authenticated request.

The origin is fixed to `https://sift-analytics.vercel.app`. One anonymous GET must return homepage 200. Only same-origin, query-free `/_next/static/chunks/*.js` or `/_next/static/immutable/chunks/*.js` script paths are extracted, with at most 15 fetched. A complete client bundle must contain **Choose a folder**, **Import selected** and **Choose a data folder**. The complete original homepage and matched bundle are retained with URLs, status, bytes and SHA256; other fetched bundles retain metadata/hashes only. This does not prove all deployed assets equal the checked source.

The same packet requires worker JavaScript GET 200, WASM HEAD 200 with `application/wasm` and no body, and an anonymous **GET** `/api/session` returning the exact existing unconfigured 503 JSON error. No POST, session cookie, account, application form, model route or production write is used. A redirect/401/other unexpected response fails; there is no authentication or alternate-URL retry.

Every response has a 1 MiB bound (session 64 KiB), the overall received-body budget is about 6 MiB, each request has a 15-second deadline including terminal observation, and total HTTP work is limited to 150 seconds. Overflow destroys the request and fails. Actual `end`, message completeness, request close and socket close are required; missing terminals remain false. `Connection: close` is explicit. Bodies requested with identity encoding are original HTTP representation bytes, not TLS or compressed-wire captures. No Set-Cookie/auth values are retained: the report contains explicitly sanitized, whitelisted header JSON and sensitive-field counts only.

The manual-main-only, public Ubuntu workflow has a five-minute job cap, read-only token and exact dispatched `github.sha`. Node is 24.22.2. It installs nothing and invokes no app build, browser, database or application test. A nonce-bound 0700 runner proof directory lies outside checkout, with original HOME preserved. Existing strict source manifests bind HEAD/index/bodies/modes before and always after the packet. All new proof files are create-only. Bounded gzip/base64 records use `SIFT_HOSTED_HTTP_FILE`/`SIFT_HOSTED_HTTP_CHUNK`; an always-run artifact is a second retention channel. A failure remains a nonzero CLI/job outcome.

The four local browser cases retain their separate CI evidence. This packet cannot establish hosted-browser import, IndexedDB durability, model access or physical-device behavior.
